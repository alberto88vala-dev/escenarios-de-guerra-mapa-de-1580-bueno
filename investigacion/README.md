# Carpetas de Investigación · NotebookLM + Antigravity

Esta carpeta está destinada a guardar tus notas, resúmenes, fichas de trabajo y transcriptos generados en **Google NotebookLM** para tu tesina de Licenciatura en Historia (UNAM).

## Estructura sugerida para tus notas:
Puedes crear archivos Markdown (`.md`) o de texto (`.txt`) con la siguiente información:

- **Nombre del Sitio / Escenario:** (Ejemplo: *Presidio de Ojuelos*)
- **Categoría:** (Asentamientos, Escenarios de Guerra, Cosmovisión, etc.)
- **Coordenadas aproximadas (si las tienes):**
- **Descripción Histórica (NotebookLM):**
- **Análisis Codicológico / Pictórico:**
- **Fuentes Primarias (AGI / AGN):**
- **Bibliografía:**
